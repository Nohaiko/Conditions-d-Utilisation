# Nostaria-BOT

Bienvenue sur le dépôt officiel de **Nostaria-BOT** !

Nostaria-BOT est un bot Discord conçu pour faciliter la gestion et l'organisation des serveurs Discord.

## Fonctionnalités

- Attribution automatique de rôles aux nouveaux membres.
- Message de bienvenue automatique.
- Système de tickets pour l'assistance.
- Outils de gestion et d'administration du serveur.
